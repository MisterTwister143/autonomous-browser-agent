**AI-агент, который автономно управляет браузером для выполнения сложных многошаговых задач.**

## **Что делает этот проект**

Обычная автоматизация браузера требует:
- Заранее написанные сценарии
- Жестко заданные CSS/XPath селекторы  
- Ручную обработку ошибок
- Статические деревья решений

**Наш агент предоставляет:**
- **Автономное принятие решений** - ИИ анализирует каждую ситуацию
- **Динамический поиск элементов** - Находит элементы по контексту, а не фиксированным селекторам
- **Интерактивные уточнения** - Спрашивает недостающую информацию
- **Контекстное выполнение** - Помнит историю и состояние задачи
- **Адаптация в реальном времени** - Реагирует на изменения страниц и ошибки

### ***Примеры использования*** 

Пример 1: Многошаговая навигация

Введите задачу: "перейди на википедию, найди статью про ИИ"

Агент выполнит:
1. Перейдет на Википедию
2. Найдет поле поиска
3. Введет "ИИ"
4. Нажмет на соответствующую статью
5. Подтвердит выполнение

Пример 2: Интерактивная задача (недостающая информация)

Введите задачу: "закажи пиццу"

Агент выполнит:
1. Определит недостающую информацию (адрес, тип пиццы)
2. Спросит: "Какую пиццу вы хотите и на какой адрес доставить?"
3. Использует предоставленную информацию для перехода на сайт доставки
4. Попытается найти ресторан и добавить в корзину

Пример 3: Обработка ошибок

Введите задачу: "закажи пиццу" → "Domino's, пепперони, адрес: ..."

Агент выполнит:
1. Попробует dominos.ru (не работает в России)
2. Проанализирует ошибку: "Domino's Pizza больше не работает в России"
3. Спросит об альтернативах: "Хотите попробовать другую пиццерию?"
4. Адаптируется на основе ответа пользователя
